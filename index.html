6. I'd like to · I wouldn't like to
📋 Примечание:
• I love / enjoy / like + V-ing (я люблю что-то делать) → I like watching films (я люблю смотреть фильмы)
• → I'd like to + V (хотел бы) → I'd like to watch films (я бы хотел посмотреть фильмы)

• I don't like / don't enjoy + V-ing → I don't like watching films
• → I wouldn't like to + V → I wouldn't like to watch films

Пример: I love eating Italian food, so I'd like to visit Italy. I don't enjoy cold weather, so I wouldn't like to live in Russia in winter.
